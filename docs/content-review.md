## 内容更新步骤

1. 在数据文件中同步维护中英文，避免只更新其中一种语言。
2. 日期、公司名、资质名称以本人材料为准，保留历史区间，避免自动计算未经确认的工龄。
3. 若新增指标，先明确本人角色、数据来源、期间和单位，再加入公开文案。
4. 执行 `npm run verify`，浏览受影响的两种语言页面及打印版。
5. 确认后按本人 GitHub / Vercel 流程发布。
