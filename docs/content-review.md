## 动效与案例图片

首页工作照和生活照片有桌面视差。`projects.js` 中的 `approvedMedia()` 仅在素材标记 `publicationStatus: 'approved'` 后返回数据，所有案例默认 `media: null`。

PRD 的 Porsche 图片视差参数已经定义在 `src/site/parallax.js`：从 -28px 到 28px。由于照片对应关系待核对，本版不渲染图片或该段动画；案例文字和链接完整可用。后续启用时应补齐对应尺寸的图片、替代文本，并重新检查资源预算及裁切边界。

## 内容更新步骤

1. 在数据文件中同步维护中英文，避免只更新其中一种语言。
2. 日期、公司名、资质名称以本人材料为准，保留历史区间，避免自动计算未经确认的工龄。
3. 若新增指标，先明确本人角色、数据来源、期间和单位，再加入公开文案。
4. 执行 `npm run verify`，浏览受影响的两种语言页面及打印版。
5. 确认后按本人 GitHub / Vercel 流程发布。
